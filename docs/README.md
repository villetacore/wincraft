# WinCraft: проектирование и развитие

Дата: 14 октября 2026 года. Статус: план обновлён по исходникам WinCraft 0.3 и согласованному направлению Linux + Rust-окружение + управляемый Wine; собственное ядро исследуется отдельно. Предлагаемые компоненты, версии этапов и критерии ниже — план, а не уже реализованные возможности. При последнем анализе прошли два теста cargo test --locked на Windows-хосте; Linux-init они не проверяют. Сборка ОС и запуск VM не выполнялись.

**Цель:** открытая настольная Unix-подобная ОС с собственным системным окружением на Rust, установочным ISO и максимально широкой, проверяемой совместимостью с Windows-приложениями и DOS. Долгосрочное исследовательское направление — собственное ядро на Rust.

Полная совместимость со всей историей Microsoft не является конечной спецификацией: необходимо определить платформы, версии приложений и сценарии. Windows NT, Win32, DOS, драйверы, DirectX, .NET и облачные сервисы имеют разные требования. Проект стремится расширять совместимость, но публикует только подтверждённые результаты.

## Как использовать этот план

1. Прочитать видение и текущее состояние: они разделяют желаемое и существующее.
2. Выполнить M0: закрепить исходную сборку, тесты и перечень целевых приложений.
3. Завершить M1: проверить существующий live ISO и обычного пользователя, исправить ошибки запуска, readiness и сохранения данных.
4. Выполнить M2: запуск приложений через профили runtime и реестр результатов.
5. Проверить сеть, звук и браузер в VM (M2.5), затем развивать установку, обновления, графику и реальное оборудование.
6. Исследовать собственное ядро отдельно, не связывая каждый выпуск desktop-ОС с его готовностью.

Основной архитектурный выбор этого плана — Linux как производственная база, Rust для собственного кода, Wine для Windows user mode, DOSBox для DOS и дополнительная VM для отдельных несовместимых сценариев. Linux, Rust-окружение, управляемый Wine и отдельное исследование ядра согласованы владельцем проекта 14.10.2026. DOS и VM остаются дальнейшими вариантами; главные преимущества продукта — понятная работа с приложениями и восстановление. Если собственное Rust-ядро обязательно уже в первом выпуске, применяется альтернативный маршрут из [документа о ядре](08-rust-kernel.md), с существенно меньшей начальной совместимостью.

## Термины

- **ОС WinCraft:** ядро, системные службы, окружение, приложения, сборка, установка и сопровождение как единый продукт.
- **Unix-подобная:** процессы, права, файловая система, устройства и программные интерфейсы организованы в духе Unix; сертификация UNIX не заявляется.
- **Windows-совместимая:** проходит конкретные сценарии конкретных Windows-приложений на объявленном runtime.
- **Wine prefix:** отдельное окружение с виртуальным диском C:, реестром и настройками; само по себе не обеспечивает изоляцию безопасности.
- **Runtime:** версионированный комплект Wine/библиотек/графических компонентов или DOS-эмулятора.
- **Personality:** слой, реализующий семантику другой ОС поверх базового ядра.
- **Host / guest:** система, запускающая виртуальную машину, и система внутри неё.
- **ADR:** запись архитектурного решения с контекстом, альтернативами и последствиями.
- **Gate:** условие, без которого этап не считается завершённым.
